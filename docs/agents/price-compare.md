## Cross-school price comparison (2026-11-20)

`/price-compare` (学校价格对比, menu 菲律宾游学 → 学校价格对比) puts two or three schools side by side for the same goal, room size, weeks, Sunday arrival and student conditions. Phase 1 compares CIA, EV, CPILS and CPI (CPILS and CPI added 2026-11-21; the page opens with the first two unless a school page links in; CPI's goals map to the nearest CPI course, with a note where CPI has no separate speaking course); later phases are more Philippine schools, then other countries (Burlington), then the mini program. Files are in `src/app/pages/school-compare/`:

- `school-compare.ts`: pure core (no Angular/DOM). `CompareSchool` is the adapter contract; `SchoolPriceComparison` holds the selection, matches each school's course by goal (`COMPARE_GOALS`) and room by bed count (standard on-campus rooms first, then the cheapest), and builds one `PlanCompareSheet` for both the web table and the `plan-compare` image. A school without a matching course or room gets the nearest one plus a visible note.
- `ph-compare-school.ts`: adapter for schools on the shared Philippine template; it prices one student through the school's own student class (`CiaStudentQuote`, `EvPageStudent`, `CpilsPageStudent`, `CpiPageStudent`), so the comparison never has its own prices or rules.
- `compare-schools.ts`: one source per school (identity, goal-to-course map, database name, published-revision hook). Each starts from the same content defaults as its page, and the page applies the school's published revision when one exists, as the school page and mini program do.
- `school-compare-page.component.*`: the page, with live Frankfurter rates through `connectQuoteRates`; image export is blocked without usable rates.

Rules: school fees and local fees stay separate rows and are never added together; the 学校费用差价 row compares school fees only (in 美元 when all schools charge in dollars, otherwise in renminbi). Every school is quoted as a new student. The comparison must equal each school page's own quote; `school-compare.spec.ts` checks that for several scenarios. To add a school: write its source in `compare-schools.ts`, add it to `createCompareSchools()`, extend the equality test, and set `schoolCompareId` in its page profile so its quote shows the 和其他学校比一比 link (a query with `from`, `course`, `room`, `weeks`, `start`). EV, CPILS and CPI link in; CIA has no link yet because its page is locked, but it can still be compared. CPILS's source applies the same course and room filters as its page (`cpilsVisibleCourses`, `cpilsRooms2027` in `cpils-pricing.ts`). Tests: `npx ng test --watch=false --browsers=ChromeHeadlessNoSandbox --ts-config=tsconfig.school-compare.spec.json --include=src/app/pages/school-compare/school-compare.spec.ts --progress=false`.
