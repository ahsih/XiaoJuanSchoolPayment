# study60 standalone page

Moved verbatim from AGENTS.md on 2026-11-26 to keep that file small. Record new decisions about this topic here; AGENTS.md holds only rules that apply to every task.

- `public/study60/`: the standalone static "菲律宾游学前60天英语学习计划" page at `https://sidaqihang.com/study60/` (user handoff 2026-11-17). It is a plain HTML/JS single page with hash routing, 1,050 mp3 clips and images; Endpoint routing selects `MapFallback` before `UseDefaultFiles` can rewrite a directory request, so the fallback in `Program.cs` (`FindStaticSiteIndex`) serves a wwwroot folder's own `index.html` with `no-cache` (after a 301 from `/study60` to `/study60/`, which its relative `audio/` and `img/` links need) before `SpaSeoHtmlRenderer` runs; it never passes through the Angular router. A local static server does not reproduce this routing order, so check `/study60/` on the live site after server changes. Do not edit `index.html` directly: it is generated by `study60/src/build.py`. Its menu entry (游学指南 → 游学前60天英语学习) uses `external: true` in `navigation.config.ts`, which the navbar renders as a plain `href` because `routerLink` would hit the `**` redirect to home. Learning progress lives only in each student's `localStorage` (`sida60:` prefix); there is no backend. Keep it free of external CDNs, fonts and analytics.

- `study60/`: source for `public/study60/` from the user's handoff package. `README-交接说明.md` is the original handoff guide; `README.md` lists the repository differences. Change course text only in `src/data.base.json` (final-test questions, contact details and home-page entries are in `src/app.js`) and follow handoff section 6 from this folder: `python3 tools/gen_clips.py`, `tools/tts_run.py` (only for changed English; delete the old mp3 first), `tools/rec_list.py`, then `src/build.py`. The scripts were adjusted to write straight into `xiaojuanschoolpayment.client/public/study60/` (and the recording list to `study60/录音清单.csv`, which stays unpublished); pushing to `main` is the "upload". Python 3 is required and was not installed on the user's PC as of 2026-11-17; TTS also needs `kokoro-onnx`, `soundfile`, ffmpeg and the untracked model files in `tools/kokoro/`. Do not regenerate content from the original PPT, and always write the brand as 思达启航.
