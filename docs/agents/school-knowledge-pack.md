# School knowledge pack (百问百答 bot)

Moved from AGENTS.md on 2026-11-26 to keep that file small. Record new decisions about this tool here; AGENTS.md holds only rules that apply to every task.

- `tools/school-knowledge-pack/`: builds the knowledge pack for the planned 百问百答 student Q&A bot (user request 2026-11-24). The bot must answer from the schools' own materials on the user's G: drive, never from the website. `node tools/school-knowledge-pack/build-pack.cjs` (options `--dry-run`, `--only <path part>`, `--out <folder>`) reads every country's school folders plus any `学校最新资料（…）` folder inside the pack (newest school packs in city+school folders such as `宿务CG`, treated as the newest copies; its folders marked 内部/不对外 are skipped), converts PDF (pdftotext), Word/Excel (hidden Office through `convert-office.ps1`, macros off), pptx and scans/images (Windows OCR through `ocr.ps1`), and writes `G:\思达启航学校资料包`: `当前资料` (2025 and later, one Markdown file per school, to upload), `旧资料` (older or superseded versions, not uploaded), `资料目录.csv` (where every file went and why) and `使用说明.md` (copied from this folder, with the bot prompt). It drops student files, contracts, account, payment and payroll files, CVs, agent manuals, permits, other markets' price lists, our own quotes and 公众号 articles, score reports and any document with commission rates or tables, agent/NET prices or agent discount caps (`AGENCY_PRICE`). Notices addressed to agencies are kept for their prices, dates and rules: `stripAgency` removes the salutation and agent-directed sentences, drops a page when at least a quarter of its lines are agent-directed, and drops the file when every page is. It removes school phone, email, website, address, social-account, 公众号 and bank-account lines, and writes 思达 as 思达启航 and 台湾 as 中国台湾 (`normalizeWording`). The PowerShell scripts must stay ASCII-only (PowerShell 5.1 reads them as ANSI). It runs only on the user's PC; nothing is deployed.
