## 已实现

页面参考现有CIA组件、内容宽度、卡片、锚点、展开相册、报价表单和共享报价图片样式，使用La Mer独立内容与实景。包含学校概况、选校建议、位置交通、四种普通课程、亲子课程、日常作息、普通与家庭住宿、餐饮服务、费用优惠、校规和常见问题。原9份PDF共72页和完整海报已经整理，照片与视频保留来源记录。

普通报价支持1–20人，各学生独立课程、住宿、签证、日期和分段计划，支持1–24周。人数切换保留未启用成员输入，但不计入总额。日期、空档、重叠、覆盖范围或价格无效时禁止导出正式报价。注册费仅收一次，优惠按每位学生独立判断。

亲子入口保留独立输入，支持已公布的2–4人套餐、任意至少一名监护人加一名儿童组合、儿童年龄和各成员签证。价格按实际适用版本与档期选取，保留每个1/2/3/4/6/8周学校整包原价。学校活动覆盖监护人与儿童，先减每人每周50美元，再将整个剩余套餐95折；活动不适用时仍95折。套餐已含费用不重复计算，签证续签和可退住宿押金按人另列。

网页费用结果、PNG和员工图片预览调用同一数据构造器，金额由数值计算，不解析格式化字符串。原价、学校优惠、思达优惠、注册费、当地费用、参考项目、订金和余额分别列示。图片高度随明细增长，支持预览与下载，失败时保留已有明确提示。人民币使用现有汇率服务，包含实际比率、来源与日期；不可用时明确标注备用汇率。

学校内容、课程住宿价格、亲子版本与套餐、当地费用及包含关系、优惠日期与数值、图片文案、素材顺序及显隐均接入独立版本化内容。已发布版本优先于初始化数据；顾问草稿需要提交审核，管理可退回或发布。媒体上传先保持未公开，随版本发布生效。编辑预览复用真实公开页面，双向定位与橙色高亮可用，切换标签不重载预览或重置报价方案。

数据库初始化仅插入缺失记录及待审核的初始草稿；不新增La Mer专用表、不改模型快照、不覆盖已有记录。EV主校区保留独立查询与功能。路由、目录、导航配置、员工学校列表、SEO、分享图和sitemap均已接入。

## 验证结果

- La Mer费用及数据回归：38项通过，覆盖普通1/2/3/4/8周、短分段满4周折算、不同课程住宿分段、双向同步、无效日期与覆盖、多人独立条件、注册费、两级优惠、开课日期边界、亲子精确价格、季节/版本、人数年龄限制、订金余款、当地费用、已发布数据优先和编辑文案生效。
- 共享报价图片布局回归：4项通过。补齐旧测试依赖，并将旧的固定页脚高度限制改为检查全部文字仍在PNG内，适应可变长度的已发布说明。
- 公开浏览器验证：23项通过，检查目录入口、SEO和分享图、导航配置、单人/3人/20人报价、输入保留、亲子及受限方案、相册分类缩略图、全部图片加载、1440/768/390/320像素布局和PNG预览下载，无浏览器异常。
- 员工浏览器验证：12项通过，检查真实页面预览、改价即时反映、内容双向定位、高亮、媒体标签保持同一iframe、保留8周方案、公开页不读取未保存预览草稿，以及亲子图片使用同一计算。
- 本地API审核流程：9项通过，包含顾问发布被拒绝、管理审核队列、退回、发布、已发布价格不被新草稿覆盖。媒体另验证上传未公开、草稿未公开、发布生效和恢复基线。测试照片已清理，测试修改没有留在公开基线中。
- Angular生产构建通过；ASP.NET Core后端构建通过，0错误。后端仍有原有SchoolService的4处可空引用警告，La Mer未新增此类警告。
- 网页sitemap响应包含新地址；前端默认配置与后端嵌入初始JSON完全一致。再次启动后端初始化没有覆盖已有La Mer已发布版本。

数值核对：普通4周示例为1,791美元，学校减免200美元、思达减免89美元、注册费100美元。2人4周标准双人亲子套餐为3,800美元，订金1,000美元、余款2,800美元；两人可退住宿押金6,000比索另列。3人直通泳池套餐样例原价7,100美元、学校减免600美元、思达减免325美元，应付6,175美元，订金1,500美元、余额4,675美元。

实际使用Chrome进行桌面和移动视口验证；复用了现有手机/微信图片预览和长按保存流程，未进行真实微信或iOS设备验收。

## 仍需按具体方案核对

1. 跨亲子淡旺季、跨方案版本、未公布周数或房型，没有明确混合计价方式，当前阻止正式导出并提示顾问核价。普通有效套餐正常使用。
2. 2027普通课程旺季表尚未提供，涉及2027的普通报价提示附加费须核对；不拿亲子或其他校区档期代替。
3. 普通多人共车接机的收费单位，以及预先安排换课换房是否触发现场变更费，资料未明确。接机保留参考金额、不乘总人数；变更费保留必要说明、不擅自重复计入。

已由用户确认的2025普通价、500美元/人订金、亲子组合、套餐外按人费用及两级优惠均已实现，不属于待确认事项。

## 后续维护与复查

员工发布后，公开页面、计算器及报价图片共同读取新版本。修改校园默认资料时，在客户端目录运行：

```text
node scripts/generate-la-mer-seed.cjs
node scripts/generate-la-mer-seed.cjs --check
npx ng test --watch=false --browsers=ChromeHeadlessNoSandbox --ts-config=tsconfig.la-mer.spec.json --include=src/app/pages/philippines/la-mer-school/la-mer-quote.spec.ts --progress=false
npx ng test --watch=false --browsers=ChromeHeadlessNoSandbox --ts-config=tsconfig.quote-image-layout.spec.json --include=src/app/components/quote-image-layout.spec.ts --progress=false
npx ng build --configuration production
```

浏览器复查脚本为客户端 `scripts/verify-la-mer-page.cjs`，需要可用的Playwright与Chrome。`PLAYWRIGHT_MODULE`可指定现有Playwright模块位置，`LA_MER_BASE_URL`可覆盖默认本地地址；脚本不修改数据库，会更新文档目录的验收图片。

完整来源见[资料与规则对照](la-mer-source-audit.md)、[源文件页数与摘要](la-mer-source-index.json)、[素材与PDF页码映射](la-mer-media-sources.json)。接口及浏览器验收明细在 `qa/ev-la-mer/` 的JSON报告中；没有将本地测试账号或凭据写入交付文件。
