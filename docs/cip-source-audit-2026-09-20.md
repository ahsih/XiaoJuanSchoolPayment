## 1. 现状与需要修正之处

- 现有保分8周、12周课程没有锁定固定周数；IELTS Basic也未限定4周；斯巴达课程可任意搭配酒店。这些组合需限制到确有资料支持的范围。
- 页面重复出现短期比例、计算公式和多处报价入口；按仓库已有要求移除面向学生的算法说明，保留必要价格、优惠条件、费用范围。

- 当前工作区有大量其他任务未提交改动，不能覆盖、回滚或顺手重构。

## 2. 建议页面顺序

学校概览与适合人群 → 校园实景/精选视频 → 课程选择与强度 → 宿舍/酒店对比 → 学费、优惠、报价及当地费 → 入学测试与第一周 → 假期/补课/学习管理 → 校园生活与周边 → 到校后退费及其他常见问题 → 咨询入口。

导航合并为约6—7项，不要求每个子节一个导航。沿用现有品牌样式。首屏一段定位、少量特点、一个条件清楚的起价与报价入口；合并重复概览/亮点/顾问说明。正文先结论，费用用表，入学用时间线，长细则用可访问折叠区。课程表与当地费表不能变成手机横向溢出的超宽表。报价只保留一个主要操作区。

## 4. 学生需要的新增内容

### 入学与学习

- 2026年4月起ESL采用入学前OPT：听力/阅读/写作约60分钟，入学前两周的周四前完成，仅一次，独立作答，不能使用AI或辅助工具，完成后告知顾问。网页只讲流程，不公布测试直链、后台操作、校内群二维码。
- 已完成OPT者：周一08:00—09:00说明会，09:00—09:30领书及课表，09:40开课，17:00购物换汇。选择抵校纸笔测试者周二开课。替换旧“所有新生周一测试、周二开课”的安排。
- 2026-04-01专业面试通知：IELTS Intensive/Native/Guarantee、TOEIC Regular、Advanced Business必须面试，即使有官方雅思成绩也须参加；平日10:00—16:00菲律宾时间，约20—30分钟，注册后24小时内完成；通知说除面试外无笔试。
- 面试有通过/有条件通过/未通过；有条件通过先上2—4周衔接：雅思/商务为Intensive ESL或指定课程，TOEIC为Regular ESL或指定课程。实际由学校评估。
- 新通知未列TOEFL；旧通知列TOEFL且约15分钟。IELTS Basic旧手册写无面试，新OPT文件笼统排除IELTS。不能把两份名单简单合并、也不能宣称遗漏者免面试；此两课程流程待确认。
- IELTS/TOEIC从首周周六开始每周模考（2026-04-01生效），不能继续写第二周。校内分级101—601共11级；每人入学后每4周进度测试、成绩单与结业证明；不承诺固定周数提分，等级对照不等同官方成绩。
- 晚间：Intensive ESL周一至四19:00—21:00（1小时课+1小时自习）；IELTS系列周一至四19:00—22:00（2小时课+1小时自习），周五19:00—20:00。强制/选修、自习与授课分开，青少年晚间辅导在手册标为选修。
- 2025年10月起斯巴达周六必修，非斯巴达按课程选修，不写成全校周六都自愿。周六海报有08:50开课，手册例表09:40；只介绍上午课程与下午模考，不拼接成确定精确时间表。
- 2026小考：周一/二词汇，周三语法，周四复习；有满分免复习考和最高分证书机制，未达要求需周六监督自习。资料把75%写成55/75，且把三天总题目均称单词，精确阈值待确认；8:30—9:30自习与08:50周六课冲突，不照抄时间。
- 自备电脑、耳机用于学校雅思机考训练；不要写成赴官方考场必须自带电脑。IELTS官方2026-03-05通知说明年中转机考、各市场时间不同；学校文件“7月全球一律取消纸笔”不可扩写为普遍法律/考试承诺。
- 学生权益：Buddy Teacher学习生活协助、首两周可申请调整教师/课表（需空位）、未涂写教材首周周三17:00前可申请更换、教师无故缺席向教务处申请代课或补课。简洁放在学习支持折叠区。

### 假期与补课

- `新生OT-0819.pdf`第1页：每自然月（每月第一天至最后一天）保证19天课程，因假期不足时安排补课，通常节后周六或周日；已达到19天不另补；个人缺课/疾病不补。不能解释为每人任意连续4周都有19个正式教学日。
- 每月最后一个周五上课日15:30—17:00为全校活动，不补课。与正常课堂课时区分。
- 原2026日历有日期/星期错误：3/17标周三（实际周二）；8/21标周日（实际周五）；12/8标周四（实际周二），并漏列12/25。2/25原图明确标有课。
