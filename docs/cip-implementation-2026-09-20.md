# CIP 页面实施与验收记录

日期：2026-09-20。来源以 [CIP资料审计](cip-source-audit-2026-09-20.md) 为准，只重查了有疑问的面试文字、价格行及实际采用的视觉素材。本文是内部记录，不进入公开资源目录。

## 已实施

- 路由保持 `/philippines-study/clark/cip-english-kepos`，新增单人及2—20人独立报价。七项导航；课程按目标切换对比，房型按校内／酒店切换，入学用时间线，详细当地费、接机、改期、走读和加课使用折叠区。手机表格转为可读的逐项卡片。
- `cip-pricing.ts` 为课程表、房型表和计算器共同数据源。人民币主费与比索当地费分开；默认 Light ESL + 校内三人间，四周主费8,340元，一次注册费600元，合计8,940元。历史代码中的额外500元住宿注册费没有找到本批资料或历史说明支持，已停止收取。
- 克拉克目录只为CIP显示同样的8,940元含注册参考价；共享目录组件仅增加可选价格说明，其他学校不启用。地区启动种子的CIP主费改为8,340元并注明另收600元。**未运行应用数据库初始化、未修改任何生产数据；insert-only种子不更新已有数据库记录。** CIP公开页面本来使用编译数据，本次仍保持此机制。
- Speak Up仅1／2周、IELTS Basic固定4周、保分班固定8／12周，其他项目保留各自上限；家庭四人房须明确家庭入住；青少年按资料年龄；周日抵达、周六离校，非法日期阻止报价。
- 长期优惠16／20／24周仅扣300／600／900元一次。没有自动套用学校淡季美元抵扣、免费接机、课程升级或代理折扣。
- 九档1／2／3／4／8／12／16／20／24周保留原始当地费证据；当前报价按用户后续确认的签证规则更新，宿舍净费用与可退押金分列。酒店不收校内宿舍电费、押金。教材、接机、超额电费、超住、送洗分别说明，缺失周数不插值。
- 更新2026年4月线上分级、专业面试、周一开课及首周六模考；补充学习支持、自然月19天课程规则、晚课／自习／门禁、未成年监护、餐食及生活信息。
- 假期用结构化2026表：3月20日替代错误3月17日；8月21日和12月8日星期已校正；补列4月4日和12月25日。政府假日不自动当成学校停课，缺学校通知的日期标明待确认，不外推2027年。
- 公开退费内容只包含到校后申请，不承诺未确认比例，不提供原始PDF下载。不引入内部结算、账号、测试链接、二维码或原件。
