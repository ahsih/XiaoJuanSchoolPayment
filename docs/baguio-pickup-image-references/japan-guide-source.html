バギオ留学 BESAピックアップとは

BESA（バギオ英語学校協会＝Baguio English School Association）には、フィリピン・バギオの語学学校7校が加盟しています。

加盟校：A&J / Baguio JIC / API BECI / MONOL / PINES / WALES / Junior CNS

BESAピックアップとは

BESAが運営する、マニラ空港・クラーク空港からバギオまでの共同送迎サービスです。バギオの加盟語学学校に入学する学生を、指定時間にまとめてバスやバンで移動させる仕組みです。
留学生は各学校にピックアップ費用を支払います。

対象となる空港

・マニラ空港（NAIA）
・クラーク空港

団体ピックアップの時間等について

BESAの団体ピックアップの時間や方法について、2026年9月現在の情報をお伝えいたします。

マニラ空港とクラーク空港で内容が異なります。

航空チケット購入時の注意
ピックアップ時刻より、1時間～1時間半前までに到着するフライトを選択してください。
フライトの到着時間を見て、BESAがピックアップ時間の指定をします。
例）飛行機がマニラ13:35着の場合、14:00のピックアップには乗れません。20:00のピックアップに組み込まれます。

マニラ空港でのピックアップ

※バス：4列シート、トイレ付き
※バン：7〜8人で乗車。道中でトイレ休憩を設けています。

  • 送迎は標準の交通手段としてバスで手配されます。
  • バギオ到着後は、KIA（マルコス・ハイウェイ）から各学校へ、バンで学生を送迎。

マニラ空港（NAIA） ピックアップの場所

NAIA Terminal 1（集合場所：B6）

NAIA Terminal 3（集合場所：BAY7）

クラーク空港でのピックアップ

  • クラーク空港で指定時間に集合後、学生は各アカデミーへ直接向かいます。
