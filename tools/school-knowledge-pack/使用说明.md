# 思达启航学校资料包 使用说明

这个资料包给“百问百答”机器人当知识库用。内容全部来自 G 盘里各学校发来的原始资料（价目表、宣传册、课程介绍、通知、FAQ、入学须知等），由电脑转成文字，按“国家 / 城市 / 学校”整理，每所学校一个文件。原始文件没有任何改动。

## 里面有什么

| 文件或文件夹 | 内容 | 要不要上传给机器人 |
| --- | --- | --- |
| 当前资料 | 2025 年及以后的学校资料，每所学校一个 .md 文件 | **上传这个文件夹里的全部文件** |
| 旧资料 | 2024 年及以前的资料，或者同名文件已经有更新版本的旧版 | 不上传，留着内部查 |
| 资料目录.csv | 每个原始文件放到了哪里、没放的原因（Excel 可直接打开） | 不上传 |
| 学校最新资料（2026-11） | 学校最新发来的原始资料包（按“城市+学校”分文件夹），程序会读进来整理到“当前资料” | 不上传（原件里有照片、成绩单等） |
| _处理缓存（不用上传） | 转换过程的缓存，下次更新时用来加快速度 | 不上传，也不要删 |

每份资料在文件里都写明了：学校、资料日期、原文件名。扫描件和图片是电脑识别的文字，个别字可能识别错，文件里会注明。

## 自动排除了哪些内容

机器人是回答学生的，所以下面这些不放进资料包（在“资料目录.csv”里能看到每一份的原因）：

- 学生个人资料：已报名文件夹、以学生姓名命名的文件夹、签证个案、护照、发票、录取信、成绩单、填好的表格。
- 合同、协议、代理申请表、中介手册和代理须知、账号密码、汇款和付款明细、工资单、简历和老师个人简介、会议记录、模板、我们自己的学校分析表、营业执照和办学许可。
- 学校给其他国家和地区学生的价目表（价格和中国大陆学生不同），以及文件名带 TW 的中国台湾学生版本。
- 思达启航自己给学生做的报价单（“报价”“报价单”文件夹）和自己写的公众号文章：不是学校资料。
- 含代理佣金、代理价、NET 价或代理折扣上限的文件（整份不放）。如果其中有学生需要知道的内容，可以人工删掉佣金那部分后再单独上传。
- 学校写给中介的通知（“各位中介”“Dear Partners”）：价格、日期、学校规定这些正文保留，只去掉称呼和写给中介的句子；大部分写给中介的那一页整页去掉，整份都是写给中介的不放。
- 学校的电话、邮箱、网址、地址、社交账号、公众号和银行收款账户（整行去掉）：学生只能通过思达启航报名和付款。
- 资料里的“思达”统一写成“思达启航”，“台湾”统一写成“中国台湾”（同一行里的“中国”写成“中国大陆”）。
- 照片和视频；图片只识别价目表、通知、海报、课表这一类。

资料日期取离文件最近的日期（文件名里的，或最近一层文件夹名里的）；同一份资料有几个版本时，按收到的先后（外层的日期文件夹）留最新的。“学校最新资料”文件夹里的文件算最新收到的。

## 怎么做机器人

1. 在扣子（coze.cn）、腾讯元器等智能体平台新建一个智能体。
2. 新建一个“文本/文档知识库”，把“当前资料”文件夹里的所有 .md 文件上传进去（一所学校一个文件）。
3. 把下面的提示词贴到智能体的“人设与回复逻辑”里。
4. 用真实问题测试，例如“CIA 四人间4周多少钱”“EV 可以带小孩吗”“碧瑶 PINES 的雅思课一天几节一对一”，核对答案和原文件一致后再发布。

## 机器人提示词（直接复制）

```
你是思达启航（深圳市思达启航文化交流有限公司）的游学咨询助手，用中文简短回答学生的问题。

规则：
1. 只根据知识库里的学校资料回答，回答时说明是哪所学校、哪份资料、资料日期。知识库里没有的，直接说“这个问题需要顾问帮你确认”，不要自己编。
2. 同一所学校有多份资料说法不同时，以资料日期最新的为准。
3. 价格、优惠、空房和学杂费只能作为参考，要提醒：最终费用以思达启航顾问的正式报价为准。学校资料里写给代理看的内容（例如“Dear Partners”“请代理注意”）不要原样转述给学生。
4. 不要给出任何学校的电话、邮箱、微信、网址或地址；学生要联系学校时，请他联系思达启航顾问。
5. 品牌名永远写全称“思达启航”，不写“思达”。
6. 不说“第一”“最好”“保证提分”“100%”“成功率”这类绝对化的话。
7. 提到台湾时写“中国台湾”，提到大陆时写“中国大陆”。
8. 学生想报名、要正式报价或问题比较复杂时，请他添加思达启航顾问微信，或打开 https://sidaqihang.com/about-sida/contact 。
```

## 怎么更新

学校发来新资料后，照原来的习惯放进 G 盘对应学校的文件夹（建议放进以日期命名的子文件夹，例如“2026-12-05”，程序靠文件夹名或文件名里的日期判断新旧），或者放进资料包里的“学校最新资料（年-月）”文件夹，按“城市+学校”建子文件夹（例如“宿务CG”），然后在网站代码文件夹里运行：

```
node tools/school-knowledge-pack/build-pack.cjs
```

只有新文件需要转换，其他直接用缓存。运行完把“当前资料”里有变化的学校文件在机器人平台上重新上传（替换旧文件）。
