企业微信应用

{{ weComApp?.complete ? '已启用' : '未设置' }}

设置后，提醒直接发给顾问本人（不发到群里），用企业微信的顾问还能在聊天侧边栏一键发学校页面。

在企业微信管理后台怎么设置
  1. “应用管理” → “自建” → “创建应用”，名称如“思达启航助手”，可见范围选全部顾问。
  2. 在应用详情页复制 AgentId 和 Secret（Secret 要在企业微信手机端查看）；在“我的企业”页面最下面复制企业ID。填到下面保存。
  3. 应用详情页 → “网页授权及JS-SDK” → 设置可信域名 sidaqihang.com：下载页面上的校验文件，发给技术放到网站上再验证。
  4. 应用详情页 → “企业可信IP” → 填网站服务器的IP。不知道IP时，先在下面顾问那一行点“发测试消息”，提示里会写出来。
  5. “客户与上下游” → “客户联系” → “API” → “可调用接口的应用”，选这个应用。
  6. “客户联系” → “聊天工具栏管理” → “配置应用页面”，选这个应用，名称填“发学校页面”，页面地址填下面的侧边栏地址。
  7. 在下面每位顾问那一行填企业微信账号（通讯录 → 成员详情里的“账号”），保存后点“发测试消息”。

企业微信提醒设置

填了企业微信账号、并且上面的应用已启用的顾问，提醒直接发给本人；其他顾问的提醒发到群机器人。

怎么拿到群机器人地址
  1. 在企业微信里建一个内部群，比如“学生浏览提醒”，把顾问都拉进来。
  2. 打开群聊右上角“…” → “群机器人” → “添加机器人”，新建后复制它的 Webhook 地址。
  3. 粘贴到下面“共用群机器人”里保存，再给每位顾问填企业微信绑定的手机号，提醒时会@这位顾问。
  4. 想让某位顾问单独收提醒，就单独建群和机器人，填在这位顾问那一行；没填的顾问都发到共用群。
